## Decisions Taken on Source Contradictions

Each is a default. Change it and the affected plan updates.

1. **`rating_aggregate` default.** The PDF says `0.00`; the md says `5.00`. **Chosen: `0.00`**, displayed as "No ratings yet" until the first verified review. A `5.00` default would show fake five-star ratings, which breaks the verified-reviews invariant.
2. **Margin floor.** The md requires at least 95% retention after the 3.5% fee. The PDF's 2% gateway fee takes this to 94.5%. **Chosen: floor = kitchen net after the 3.5% mesh fee ≥ 95% of list price.** The gateway fee is charged to the diner's payment, not netted from the kitchen. Plan 02 implements it.
3. **KDS timers.** The md uses green under 5 min, yellow under 8 min, red overdue. The PDF uses per-ticket SLAs of 08:00 (dine-in) and 12:00 (delivery). **Chosen: both.** Colors follow the md's thresholds; a ticket is "overdue" once it passes its PDF SLA (8 min dine-in, 12 min delivery). Plan 03 implements it.
4. **Auction expiry.** The PDF has a 90-second `expires_at` and an 18-second bid window. **Chosen: 90 seconds is the total auction lifetime; the 18-second window is the bidding phase inside it.** Plan 02 implements it.
5. **Search radius.** The PDF says "not Euclidean radii" but its SQL uses `ST_DWithin` with 5000 m. **Chosen for v1: `ST_DWithin` on geography with a 6 km radius** (18 min at 20 km/h). This is a great-circle approximation. A real routing isochrone is a later upgrade, noted in Plan 02.
6. **Pilot area.** The md uses Indiranagar in the example; the PDF uses HSR. Both are in the pilot cluster, so seed data covers both.

## Global Constraints (apply to every plan)

- Next.js 15 App Router, Server Components and Server Actions; Tailwind CSS v4; TypeScript `strict: true`; Lucide React; Framer Motion.
- PostgreSQL 16 with `postgis/postgis:16-3.4`; extensions `postgis`, `uuid-ossp`, `pgcrypto`. Redis Alpine.
- Geo columns `GEOGRAPHY(Point, 4326)`. App coordinates `{ lat, lng }`. SQL points always `ST_MakePoint(lng, lat)`.
- Money is INR, `NUMERIC(10, 2)`, rounded with `round2` (half-up).
- Mesh fee `0.035`. Statutory restaurant GST `0.05` (split 2.5% CGST + 2.5% SGST). Floor margin `0.05`.
- Auction: 90-second total lifetime, 18-second bid window. Kitchen eligible only if `active_kds_load < 0.85`. Transit radius 6 km.
- Delivery SLA integer 15–120 min; headcount ≥ 1.
- Spice levels 0–3. Allergen exclusions: peanut, shellfish, dairy, gluten.
- Ratings accepted only for a completed order, submitted within 2 seconds of UPI settlement.
- Multi-tenant isolation via RLS: tickets, sessions, margins scoped to their restaurant.
- Latency budgets (PDF): audio ingress under 200 ms, NLU under 800 ms, TTS first audio under 150 ms, glass-to-glass under 120 ms. Measured in Plan 04.
- App listens on port `3000`.
- Languages: English and Hinglish first; Tamil, Telugu, Kannada, Marathi later (not in any plan here).

## Scoped Plans (02–07)

These are detailed as their turn comes. Each will get its own file in this folder with the same header and task structure.

**02 Delivery mesh.** Covers md §5 and PDF "Reverse Dutch Auction" and "Mesh Protocol".
- Matching engine (md §5), PostGIS repository, Redis Pub/Sub geohash channels, 18-second bid window, 90-second lifetime.
- `POST /api/delivery/intent` validates `DeliveryIntentSchema`.
- Route 2 UI: voice input stub, extracted metadata card, live counter-bid list, 3PL status panel.
- Acceptance: a seeded search returns ranked bundles; a bid after 18 s is rejected.

**03 Dine-in and KDS.** Covers md Routes 1 and 3, PDF "Tabletop" flows.
- `dining_tables`, `tabletop_sessions`, cart updates via `CartUpdateSchema`, station-routed `kds_tickets`, bill split (EQUAL, BY_CONSUMPTION), 5% GST, UPI dynamic QR.
- Route 1 concierge page (orb, transcript shell, filter pills, live KDS feed, settlement panel).
- Route 3 KDS: load %, station tabs, ticket board, SLA colors per decision 3, bump actions as Server Actions.
- Acceptance: a cart item fires a ticket to the right station; bumping a ticket updates the board.

**04 Voice and LLM.** Covers md §1 voice pipeline and PDF latency section.
- LiveKit Cloud client hooks, Silero VAD WASM wrapper, Deepgram Nova-3 adapter, Sarvam translation adapter, Cartesia TTS trigger, canvas audio-reactive orb.
- LLM orchestrator: Gemini 2.5 Flash or Claude Haiku with `temperature: 0.1`, tool schemas as Zod, validated output.
- Mockable: every provider has a fake adapter used in tests.
- Acceptance: a recorded utterance produces a validated `CartUpdate`; latency budgets measured and logged.

**05 Auth, profile, ratings, compliance.** Covers md Routes 4 and 5, PDF auth and tax sections.
- Phone-first `+91` identity, OTP via Supabase auth with Twilio or MSG91 (simulated in dev), saved UPI VPAs, 15-character GSTIN, FSSAI 14-digit validation.
- Razorpay and Cashfree webhook signature verification.
- Rating modal: 1–5 stars, tags (`Authentic Taste`, `Fast Prep`, `Piping Hot`, `True Jain Spec`), gated on completed order and 2-second window.
- Acceptance: a rating without a completed order is rejected; a forged webhook is rejected.

**06 Integrations.** Covers md §1 integrations and PDF POS and ONDC sections.
- Petpooja, Restroworks and UrbanPiper webhook bridges mapping into `menu_items` via `pos_item_code`.
- ESC/POS raw socket printer on port 9100.
- ONDC Beckn BAP/BPP schema parser; Shadowfax, Rapido, Dunzo dispatch adapters (sandbox).
- Payment intent adapters for Razorpay and Cashfree.
- Acceptance: a fixture POS payload upserts the menu; a fixture order prints an ESC/POS byte stream.

**07 Edge, deploy, ops.** Covers PDF infrastructure and roadmap sections.
- Cloudflare or Envoy WAF rules as config; token-bucket rate limiting middleware.
- EC2 deploy: Docker Compose on one instance in `ap-south-1`, Caddy reverse proxy in `proxy_server/` with automatic Let's Encrypt TLS (only ports 80 and 443 published), EBS volume for `pgdata`, backups.
- Seed data: test restaurants across Indiranagar and Koramangala (PDF: "seed test restaurant nodes").
- End-to-end tests: simultaneous dine-in sessions; multi-merchant auction.
- Capacitor or React Native wrapper for the PWA.
- Acceptance: `https://<domain>/api/health` returns ok from the EC2 instance; E2E suite passes.

## Out of Scope for All Plans

- Supabase production auth tenancy, Socket.io microservice split (the PDF names it; plans 02–04 use Redis Pub/Sub and route handlers first, and a Socket.io gateway can be added later).
- The PDF's ONDC seller/buyer app and Tier 1/2 city expansion (roadmap Q5).
- Economic dashboards (the PDF's ₹49,501 example) beyond a pure function that computes the example.
